## 🤖 Ingeniería con IA (AI-First Development)

Aplico la IA generativa como parte central de mi flujo de trabajo, no como accesorio:

- **Agentes de código:** coordino OpenAI, GitHub Copilot, Claude y Cursor para generar la mayoría de la implementación en sistemas multi-archivo, manteniendo la supervisión arquitectónica.
- **Context Engineering:** estructuro repositorios, especificaciones y documentación para producir salida de IA confiable y eficiente en contexto.
- **Spec Driven Development:** traduzco requerimientos complejos en especificaciones ejecutables por máquina.
- **Human-in-the-loop:** iteración estructurada y validación ajustada al riesgo para flujos críticos.
