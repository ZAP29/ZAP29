## 🔒 DataGuard Engine

A high-performance, open-source Java library for **real-time Personally Identifiable Information (PII) sanitization**.

Designed around **O(1) Streaming I/O**, **Zero-Garbage processing**, and a **dynamic rule engine**, DataGuard Engine efficiently anonymizes massive datasets while maintaining a constant memory footprint.

### Features

- O(1) Streaming I/O
- Zero-Garbage Pipeline
- Dynamic Rule Engine
- Real-time PII Sanitization
- Comprehensive JUnit 5 Test Suite

**Tech Stack**

`Java` · `Maven` · `JUnit 5` · `Regex` · `Streaming I/O`
